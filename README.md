# User Management System

A simple User Management System built with Python to practice OOP, CRUD operations, JSON file handling, exception handling, and `match-case`.

## Features

* Add, search, update, and delete users
* Search by name or ID
* Automatic ID generation
* Duplicate user detection
* Show all users
* User statistics
* Store data in a JSON file

## Technologies

* Python
* OOP
* JSON
* pathlib
* Exception Handling
* match-case
